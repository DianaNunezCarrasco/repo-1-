# README 
## ¿QUÉ ES GITHUB?
**GitHub** es una plataforma en la nube que permite a los desarrolladores *almacenar, compartir y gestionar sus proyectos de código fuente* mediante el sistema de control de versiones **Git**.

Puedes crear proyectos *públicos*, en los que el código puede ser descargado y revisado por cualquier usuario; o *privados* en los que tu proyecto no es visible para los demás.
### Diferencia entre Git y GitHub 
***Git***: Es el programa o herramienta instalada en tu computadora que controla y registra los cambios en el código localmente.

***GitHub***: Es el servicio web en internet que aloja esos repositorios de Git para hacerlos accesibles desde cualquier lugar y permitir la colaboración en línea
